# Hello, Cargo!

Usando o Cargo para gerenciar dependências.

Comandos Úteis
---
`cargo init`  - Inicializa um projeto Cargo
`cargo build` - Builda um projeto Rust em .\target\debug\app.exe ou ./target/debug/app (`--release` gera o executável em .\target\release\ com otimizações na compilação)
`cargo check` - Vê se compila mas não gera executável
`cargo run`   - Builda e executa o arquivo gerado
`cargo new`   - Cria um projeto Cargo do zero (`--vsc` especifica a ferramenta de gerenciamento de versão, que será `git` ou `none` se a entropia do universo como um todo sempre aumentar)
